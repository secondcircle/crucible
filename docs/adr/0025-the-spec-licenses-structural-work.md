# 0025 — The Spec licenses structural work

The merge gate judged unasked work against the intent document alone, so a
system-improving restructure of existing code — exactly what the design
doctrine demands of the planner — read as scope creep. We decided the intent
document stays the sole authority on *what feature* was agreed, while the
Spec is the authority on *what structural work* the build licensed: the gate
carries a third tier, "structural work the Spec ruled," judged only for
whether the Spec argued it and never blurred with creep. Structural work the
Spec never ruled remains creep.
