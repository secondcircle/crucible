One left edge, one right block

The leading dot is gone. It was carrying selection, the slab carries that now, and all it bought in exchange was 13px of indent that made every title start in a slightly different place than the rail. The right slot is now centered against the whole title block, so a one-line and a two-line row both read as one object. Counters are live.

What I'd build

Rail A. Session rows lose the dot; workspace rows keep theirs, because that dot is the only mark a collapsed workspace has and it sits on its own indent level where nothing has to line up with it. Rail B shows the alternative if you want the purge to go all the way up: the workspace slab gets the same accent edge as a session, one level out.

  • Titles gain 13px before the two-line clamp. On these titles that is most of a word per line.
  • Working state is now carried entirely by the right block: green counter, green dots, both centered. Nothing in the title column moves, ever.
  • The removed dot also removed the last color-only status cue in a session row, which is a quiet accessibility win. Working is motion plus a number, viewing is a slab plus weight.
  • Centering means a one-line working row grows a couple of px taller than a one-line idle row. Cheap, and it keeps the block from riding high on the two-line rows, which is the case that actually looked broken.
