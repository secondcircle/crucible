2 · The return — a message to the agent, not a button for you

Agent · Opus 5
⚑ run en42 (build) completed · branch crucible/en42 · worktree .crucible/worktrees/en42 · +412 −38 · review: approved

The build run finished and its review approved. I merged crucible/en42 into our branch — fast-forward, we hadn't moved — and the suite passes here too. The run's report is in the context panel.

Completion, like every run event, is a message to the orchestrating agent: "finished in worktree X, pull it in when ready." The agent judges when — mid-task it waits, idle it merges — and resolves conflicts itself, with the session's full context. Same channel for check-ins, blockers and errors: the run asks, the agent answers or brings it to you.

Layered, top-down, fit to width. Parents above, children below, revise nodes (·r1) appear as new layers chained after their reviewers. Real runs are 2–4 wide, so the whole graph fits without zoom or pan; if a workflow ever fans wider, the graph scrolls horizontally. Click any node → its detail (view 3). No minimap, no zoom in v1.
