This page puts every one of them in the window it actually lives in. It carries the app's own CSS, so the sidebar, top bar, run strip, transcript and dialog here are the real ones, down to the pixel: this is the window, not an impression of it.

Nine misses have accumulated since the last reset. Three surfaces carry it at once and they say different things. The strip at the sidebar foot is the global count, true whichever session is open. The badge in the top bar is this session's two. The seam is one miss, at the turn it happened. The run chip's ⚠ 2 is a sub-agent's misses, which would otherwise be invisible while nobody is watching that run.

Clicking the strip opens this. 4 · Badge and chip, beside what they mark

Both are counts, so both use the badge idiom Mock G set: ⚠ N. One deliberate change from that mock. It drew the badge in error red; here it is amber, because in the app as built red is failure (a failed run dot, an error card) and a cache miss is money, not breakage. The quota strip's own over-pace numbers are amber for the same reason.

5 · What this binds, and the two calls I made

  • The strip is a button, the quota rows are not. Its stylesheet says "Nothing here is clickable, focusable or hoverable, which is why the component takes no callbacks at all". That stays true: the cache strip is its own component above the quota block, not a quota row.
  • Amber, not red, for the badge, the chip mark and the money. Mock G used red before the app had a red. Say the word and it goes back.
  • The seam has no action. Mock G's seam carried a view log link. The badge already jumps here and the strip already opens the view, so a third path is one too many. The seam states facts and stops.
  • Retention is on the dialog, not just in the ledger. It is the setting the whole experiment is about, so seeing it beside the bill is worth the line. Cut it if the dialog should stay pure counts.
  • Mock G's session header is gone. That mock put the badge in a per-session shead the app never built; the top bar is where the per-session cost and context live now, so the badge goes beside them.
