Spec — the panel handoff crosses the agent port

The renderer never learns a file path. panel_show reaches the main process through the port, and the main process answers with a tab id.

Boundary

  • Preload exposes exactly three calls, none of them taking a path.
  • The scheme handler asks the panel model whether a file is servable.
  • A tab keyed by path refreshes in place rather than stacking.

Acceptance

npm test -- panel
npm run typecheck

Re-showing the same file must not create a second tab. A closed tab makes its file unservable on the next request.

The reader takes the transcript's place, not the screen's. Graph and rail stay put, so you can walk one artifact to the next without leaving the run. Markdown renders as markdown, HTML renders as the page it is, anything else shows as plain text. Esc puts the node's transcript back. Reveal in Finder and Copy path are there for the file itself; nothing in this view writes.
